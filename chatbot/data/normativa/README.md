# Normativa indexada

Este directorio contiene, en Markdown u otro formato de texto plano, la normativa que el índice FAISS considera para responder consultas.

Referencia mínima para Fase 2:

- Código Penal de la Nación (partes generales relevantes para consulta ciudadana).
- Código Procesal Penal de la Provincia de Buenos Aires.
- Ley 24.240 — Defensa del Consumidor.
- Ley 20.744 — Contrato de Trabajo.
- Ley 26.485 — Protección integral a las mujeres.
- Ley 24.522 — Concursos y Quiebras.

Todos los archivos deben venir de fuentes oficiales (Infoleg, SAIJ) y llevar en el encabezado la URL y fecha de descarga.
